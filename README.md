## Problem Statement

After a ranked match on AlgoArena, the system displays your rating change in compact form. A rating of 1500 that becomes 1520 shows as 1520, but veterans prefer the classic shorthand: keep the first digit, count the digits in between, keep the last digit. Your task is to implement this display.

You are given a string s of length at least 3 consisting of lowercase English letters. Output its compact form: the first character, then the count of characters between the first and last, then the last character.

## Input

```
s
(3 ≤ |s| ≤ 100, |s| denotes the length of s. s consists of lowercase English letters.)
```

## Output

```
Print the compact form of s: first character, number of characters between first and last, last character.
```
